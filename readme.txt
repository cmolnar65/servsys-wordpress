Field service management for WordPress.

== Description ==

ServSys is a WordPress-based field service management system. The plugin is currently under active development.

Current functionality includes customer, site, customer-note, and equipment management. Equipment records are always assigned to a customer site.

== Installation ==

1. Upload and activate the ServSys plugin.
2. Open ServSys in the WordPress administration menu.
3. Configure customer and equipment types as needed.
